# RizqEngine: portfolio description

**Image:** `banner.png`
**One line:** A web-based point-of-sale and inventory system with multi-warehouse stock and printable business documents.

**CV (short):** Point-of-sale and inventory system for shops with several warehouses. Handles products and barcodes, stock adjustments and transfers, PDF invoices and role-based staff access (from Super Admin to Cashier).

**Portfolio:** RizqEngine is a point-of-sale and inventory system built for everyday retail work. Cashiers sell quickly, managers track stock across warehouses, transfers and adjustments are recorded, and PDF documents and barcode labels can be printed. Access is controlled by role.

**Stack:** Laravel 13, Livewire 4, Tailwind CSS 4, DomPDF, barcode labels
